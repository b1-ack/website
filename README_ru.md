# B1ack - официальный сайт

**Спокойствие всегда здесь.**

</div>

Исходный код [b1ack.net](https://b1ack.net) - быстрого статического сайта без зависимостей, созданного на чистых **HTML, CSS и JavaScript**. Никаких фреймворков, никакой сборки, никакого бандлера - просто чистая разметка, отдаваемая браузеру напрямую.

---

## ✨ Обзор

B1ack - это веб-представительство проекта B1ack и дистрибутива **B1ackOS GNU/Linux**. Помимо landing-страницы, сайт содержит небольшую коллекцию самостоятельных служебных инструментов, оформленных в едином, минималистичном стиле.

## 🧩 Возможности

- **Многоязычность по замыслу** - весь сайт полностью локализован на **английский, русский, немецкий, французский и грузинский** языки, с корректными альтернативами `hreflang` и постоянным переключателем языка.
- **Светлая и тёмная темы** - переключение в один клик с сохранением выбора между посещениями.
- **Адаптивная навигация** - динамическая шапка со сворачиваемым меню для небольших экранов.
- **Поиск погоды** - просмотр текущего прогноза для любого города мира.
- **Инспектор отпечатка браузера** - покажет, какую именно информацию о вас раскрывает ваш браузер.
- **Генератор безопасных данных** - создание надёжных паролей и случайных защищённых данных на лету.
- **Руководства по выживанию и техническим вопросам** - справочные страницы с практическими знаниями и технической информацией.
- **Страница пожертвований** - простой способ поддержать проект.
- **Разметка с учётом SEO** - структурированные данные, мета-теги Open Graph и Twitter, канонические URL и карта сайта из коробки.
- **Раздел B1ackOS** - отдельный локализованный раздел, представляющий дистрибутив B1ackOS GNU/Linux.

## 🛠 Технологический стек

| Слой       | Технология                     |
|------------|---------------------------------|
| Разметка   | Семантический HTML5             |
| Стили      | Современный CSS3 (кастомные свойства, без препроцессора) |
| Логика     | Чистый JavaScript (ES6+, без фреймворков) |
| Инструменты | Не требуются - открыл и работай |

Проект намеренно избегает инструментов сборки: всё отображается «как есть», что делает кодовую базу прозрачной, лёгкой и удобной для аудита.

## 🌍 Локализация

Каждая ключевая страница переведена и доступна по собственному языковому пути, с автоматическим определением языка и выпадающим списком для ручного переключения. Поисковые системы направляются с помощью альтернатив `hreflang`, чтобы каждая языковая версия индексировалась корректно.

## 🎨 Философия дизайна

Интерфейс отдаёт предпочтение спокойной, минималистичной визуальной подаче - приглушённые палитры, щедрые отступы и сдержанная анимация - перекликаясь с собственным слоганом проекта. Тёмная и светлая темы следуют одним и тем же принципам, обеспечивая единообразное впечатление при любом освещении.

## 🚀 Начало работы

Поскольку у сайта нет зависимостей для сборки, запустить его локально проще простого:

1. Склонируйте репозиторий.
2. Раздайте корневую директорию любым статическим файловым сервером (или откройте страницы напрямую в браузере).
3. Пользуйтесь - не требуется ни установка, ни компиляция, ни менеджер пакетов.

## 🔌 API

За сайтом стоит небольшой публичный API по адресу **`api.b1ack.net`**, предоставляющий несколько лёгких эндпоинтов, не требующих авторизации:

| Эндпоинт | Описание |
|---|---|
| `/ip` | Возвращает публичный IP-адрес вызывающей стороны в формате JSON. |
| `/trace` | Возвращает диагностическую информацию о соединении, по духу похожую на `1.1.1.1/cdn-cgi/trace` от Cloudflare. |
| `/weather` | Проксирует данные о погоде для заданного набора координат, возвращая текущие условия в формате JSON. |
| `/issue` | Позволяет создать issue на GitHub напрямую с помощью POST-запроса - токен GitHub, используемый для авторизации запроса, хранится на стороне сервера и никогда не раскрывается клиенту. |

Чтобы использовать `/weather`, отправьте `GET`-запрос с параметрами `latitude`, `longitude`, нужными параметрами `current` (например, температура, код погоды, скорость ветра) и `timezone` - ответ вернётся в виде структурированного JSON.

Чтобы использовать `/issue`, отправьте `POST`-запрос с телом JSON, содержащим `title`, `body` и опциональные `labels`, а также заголовок `Origin`, идентифицирующий вызывающий сайт (например, `os.b1ack.net`). После этого API создаёт соответствующий issue на GitHub от вашего имени, ни разу не раскрывая используемые учётные данные.
